# ダミーデータ

本ディレクトリには、プロジェクト（`ir-web`）で使用したダミーデータが含まれる。
init_dataには5段階評価、dataset_for_checkには11段階評価のダミーデータを入れている。

本ダミーデータは実際の教学データを使用していない。

## 概要
- **init_data**
2017年度開学の国⽴⼤学を想定しており、2025年度までの8年分を⽤意した。
理学部と⼯学部の2学部で、理学部には化学科と物理学科を⼯学部には情報学部を設置している。成績評価は5段階である。

- **dataset_for_check**
2017年度開学の国立大学を想定しており、2025年度までの8年分を用意した。
12個の学部を設置している。成績評価は11段階である。
